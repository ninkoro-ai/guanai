# 客户生日关怀助手

面向银行客户经理的轻量化客户关系维护工具：客户编号管理、生日自动提醒、祝福辅助、维护记录沉淀。数据仅保存在本机浏览器（IndexedDB），无服务器、零成本、隐私友好。

## 功能

- 首页仪表盘：今日生日、未来 7 天（不含今天）、A 类客户统计
- 客户管理：新增、编辑、删除、搜索、按等级/时间/行业筛选；客户详情页含历史维护记录
- Excel 批量导入：模板下载、智能生日解析、校验、重复处理（覆盖/跳过）、错误报告、导入后可撤销
- 数据导出：客户与维护记录
- 生日提醒：提前 7 天提醒；当天 A 类客户 09:00 / 10:00 / 14:00 提醒
- 祝福助手：本地离线智能生成（行业 + 备注关键词），随机组合 30-80 字微信风格祝福
- 维护记录：电话/微信，自动记录日期，支持二次编辑
- PWA 离线可用：首次访问后自动缓存，断网也能查看和记录；可安装到桌面/主屏
- 单文件构建：`dist/index.html` 自包含全部代码，双击即可本地使用
- 隐私说明：不保存身份证、账号、完整姓名、交易信息

## 本地开发

```bash
npm install
npm run dev
```

## 测试与构建

```bash
npm test
npm run build
npm run preview
```

应用图标（橙白主题）重新生成：

```bash
npm run icons
```

浏览器冒烟测试（自动走查主要流程并截图，优先使用系统 Edge）：

```bash
npm run smoke
```

## 部署

- Vercel：导入仓库，框架选择 Vite，构建命令 `npm run build`，输出目录 `dist`
- GitHub Pages：构建产物在 `dist/`，已配置 `base: './'`，可直接托管

`dist/index.html` 是自包含单文件，直接双击即可在本机使用（无需服务器）；
PWA 的安装与离线功能需要 http/https 环境（本地 `npm run preview` 或部署后生效）。

## 离线与安装

构建产物包含 Service Worker 与 Web App Manifest（`sw.js`、`manifest.webmanifest`）。首次在线访问后资源自动预缓存，之后断网仍可正常使用；Chrome / Edge 中可通过地址栏安装图标或“安装应用”菜单安装到桌面/主屏。

## 数据说明

仅保存：行内客户编号、客户简称、生日（支持仅月日）、性别、行业、客户等级、备注。
不保存：身份证号码、银行账号、完整客户姓名、客户交易信息。
